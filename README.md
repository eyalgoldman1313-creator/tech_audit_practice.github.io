# ביקורת מערכות מידע ממוחשבות בשילוב AI — אפליקציית תרגול

אפליקציית ווב חד-קובצית (single-file HTML) לתרגול לקראת הבחינה בקורס **ביקורת מערכות מידע ממוחשבות בשילוב AI**.
עברית מלאה (RTL), mobile-first, עובדת גם offline מ-`file://` וגם ב-GitHub Pages. ללא backend; התקדמות ותשובות נשמרות בדפדפן בלבד.

🔗 **האתר:** https://eyalgoldman1313-creator.github.io/tech_audit_practice.github.io/
📘 **המדריך:** https://eyalgoldman1313-creator.github.io/tech_audit_guide.github.io/

## מה כלול
- **בחנים לפי נושא** — מאות שאלות ברירה ב-11 נושאי הסילבוס, משוב מיידי או בסוף, הסבר לכל מסיח ומקור מדויק; תרגול חוזר של שאלות שטעיתם בהן.
- **מצב מבחן משוקלל** — סט לפי תדירות הנושאים בבחינות, עם טיימר, ציון ופילוח לפי נושא.
- **סימולציית קייס** — שאלות פתוחות אמיתיות ממבחני הקורס ומבחינות המועצה 2015–2025, מפוצלות לסעיפי "נדרש": כותבים תשובה, חושפים פתרון רשמי ומסמנים בדיקה עצמית לפי נקודות מפתח.
- **מבחן מלא** — מבחני הקורס (כולל מועדי 2026) בתנאי אמת עם טיימר.
- **מפתחות מושג** — כרטיסיות, טבלאות השוואה ועצי החלטה.
- **מפת בחינות המועצה** — איזה נושא נשאל באיזו בחינה, עם קישור לקייס.

## מבנה ופיתוח
- `index.html` — האפליקציה הבנויה (GitHub Pages).
- `source/` — קוד המקור (Vite + React + TypeScript): `npm install` · `npm run dev` · `npm run build` → `dist/index.html`.
- `source/src/data/*.json` — בנק השאלות, הקייסים, המבחנים ומפתחות המושג.
- `source/content-src/` — קבצי הניתוח המקוריים וסקריפט האיחוד (`merge.py`).
